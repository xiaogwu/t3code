# Agent sounds

T3 Code can play a short local sound when an agent needs approval or input, finishes a turn, or fails.

Choose **Settings → General → Agent sounds** and select **When unfocused** or **Always**. The setting is local to the browser profile or desktop installation; it does not change other devices.

Browsers require an interaction after reopening T3 Code before they allow sounds. T3 Code never replays an old thread state after loading or reconnecting.
